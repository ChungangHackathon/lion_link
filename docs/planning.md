# LION LINK 기획서

> 멋쟁이사자처럼 중앙대학교 동문 네트워크 플랫폼
> 출처: 아이디어 제출 자료(LION_LINK.pdf), 킥오프 회의(11/1), 2차 회의(11/4), 기능명세서 v1.17
> 마지막 갱신: 2026-11-12

## 한 줄 소개

기수 단위로 나뉜 멋사 중앙대 동문을 **직무·관심 분야로 찾고, 커피챗·채팅·커뮤니티로 바로 연결**하는 서비스.

> 활동은 한 기수, 연결은 모든 기수. — One Community. Every Generation.

## 배경

- 멋사 중앙대는 매년 약 30명이 새 기수로 들어온다. 14개 기수를 더하면 잠재 동문은 약 420명이다(14기 × 30명 단순 추정, 실제 명단 통계 아님).
- 하지만 활동이 기수 단위로 진행돼서, 기수와 기수를 잇는 구조가 없다.

## 문제 정의

| 문제 | 상황 |
| --- | --- |
| 1. 기수 간 네트워크 단절 | 다른 기수와 만날 기회가 적다. 어느 선배가 백엔드 분야에 있는지 모른다 |
| 2. 지식과 경험의 분산 | 선배들의 학업·취업·프로젝트 노하우가 흩어져 있다. 취업 준비 경험을 찾아볼 곳이 없다 |
| 3. 활동 종료 후 소속감 약화 | 활동이 끝나면 관계를 이어갈 접점이 줄어든다. 졸업한 선배에게 연락할 통로가 없다 |

킥오프에서 합의한 초점은 **기수 간 단절**이다. 기수 내 단절은 매주 만나며 스스로 풀 수 있지만, 기수 간에는 누가 있는지조차 모른다.

## 타겟

| | 메인: 14기 재학생 (현재 기수) | 졸업생 · 이전 기수 |
| --- | --- | --- |
| 원하는 것 | 다른 기수 선배의 경험을 얻고 싶다 | 다른 동문과 연결되고 새로운 기회를 얻고 싶다 |
| 쓰는 이유 | 취업·진로 상담(현직 선배에게 커피챗), 학업 정보(시험·수업 자료), 스터디·프로젝트 참여 | 커리어 네트워킹, 사이드 프로젝트·창업 팀원 모집, 채용 공유와 후보 탐색 |

- 서비스의 성패는 **선배들의 참여 의지**에 달려 있다. 새로운 사람 만나는 걸 좋아하는 선배를 우선 타겟으로 하고, 운영진(회장) 경로로 이전 기수를 설득한다(킥오프).
- 선배 참여 의지 확인을 위한 설문·인터뷰와 시연용 선배 섭외가 별도 과제로 있다(2차 회의).

## 솔루션

| Connect | Share | Belong |
| --- | --- | --- |
| 직무·관심 분야로 동문을 찾아 커피챗을 신청한다 | 시험 정보·취업 경험·프로젝트 노하우를 게시판에 남긴다 | 졸업 후에도 스터디·협업·채용 공유로 계속 참여한다 |

### 왜 단톡방·학교 커뮤니티가 아니라 LION LINK인가

| 기존 인맥·단체 채팅방 | LION LINK |
| --- | --- |
| 해당 분야 선배를 아는 사람에게 묻는다 | 직무·관심 분야로 검색한다 |
| 연락 가능한 동문을 수소문한다 | 프로필과 커피챗 가능 여부를 확인한다 |
| 개별로 연락해 참여 의사를 확인한다 | 서비스 안에서 바로 커피챗을 신청한다 |

## 사용자 흐름 (어느 14기 학생의 이야기)

1. **Discover**: 관심 분야(예: 백엔드)로 선배를 찾는다
2. **Connect**: 선배 프로필을 보고 커피챗을 신청한다
3. **Interact**: 커피챗이 수락되면 채팅방이 열리고 일정을 잡아 만난다
4. **Collaborate**: 스터디나 프로젝트로 관계를 넓힌다
5. **Give Back**: 다음 기수에게 경험을 나눈다 → 다시 1로

| 홈·알림 | 할 일·새 소식, 인앱 알림, 이메일 알림(커피챗 신청·메시지 요청·가입 승인) | |
| 관리자 | 가입 승인·반려 | 관리자는 DB에서 지정 |

## 주요 정책 (기능명세서 v1.17 반영)

- **가입**: 누구나 구글 계정으로 가입 신청 → 운영진이 이름·기수를 보고 승인. 승인 전에는 프로필 설정만 가능하고 다른 동문에게 보이지 않는다
- **호칭**: 화면에서는 회원을 모두 '사자'라고 부른다(선배·후배라는 말은 쓰지 않는다). 기수로 신청을 막지 않는다
- **커피챗**: 횟수 제한 없음. 같은 동문에게는 진행 중인 커피챗 1건만. 14일 무응답이면 자동 만료
- **채팅**: 누구에게나 메시지 요청 가능, 받는 사람이 수락해야 대화 시작. 커피챗이 수락되면 바로 채팅방이 열린다
- **지원 환경**: 데스크톱(웹) 기준. 휴대폰 전용 화면은 만들지 않지만 막지도 않는다
